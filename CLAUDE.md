# Squaredom (repo and folder: Cubedom)

Squaredom (title shows "v1.0", `.ver` in index.html) is a web-based, fantasy-medieval sandbox inspired by the 2000s toy "Cube World". Each character lives in a pixel-art room (a "box"). The player drags boxes onto a 5x4 board. Characters idle inside their box and sometimes visit neighboring boxes. The arrangement of boxes changes what happens.

Live site: https://forests999.github.io/Cubedom/ (GitHub Pages from `main`; pushing to `main` updates it).

## Working style
- Make small changes and test each one. Explain changes in plain language; the owner is a beginner.
- Keep this file up to date as one current reference (not a change log): when something changes, edit the section it belongs in.
- Use git; commit after each working change. Commit as Forests999 with the GitHub noreply email (already set in this repo's git config); never use the owner's real name or email.
- Ask before pushing, since pushing publishes to the public site. Before every push, raise the release number `?v=` in `index.html` (on style.css, data.js, art.js, game.js and audio.js, all five the same) so browsers and phones load the new files.
- Many functions are written on one line: never put a `//` comment in the middle of such a line (it hides the rest of the line). Put comments on their own line or at the very end of a line.
- Testing in the browser pane: the page can be throttled to about one frame every few seconds. Drive the game clock directly instead of waiting (call `step(1/30)` in a loop, advancing `T`), and back up / restore the owner's save (`localStorage` key `cubehold-v4`) around tests.
- Adding or changing an interaction, idle or item effect: add it to `COMP_TABS` (and `PAIR_WITH` for neighbor scenes), write its `NAMES` and `DESC` text, give it a tile (`T` in `buildRef`, drawn by `idleTile` or `pairDiagram` + `PD`), and make sure the game calls `markSeen` for it.

## Tech and constraints
- Plain HTML + CSS + JavaScript with Canvas. No build tools, no frameworks. It must open by double-clicking `index.html`.
- Works on desktop and mobile (touch drag, responsive layout, web app manifest `manifest.webmanifest` + `icon.svg`).
- Pixel art stays crisp: `image-rendering: pixelated` and `imageSmoothingEnabled = false`.
- Names, tags and speech bubbles are HTML over the canvas so they stay sharp. Each name label shrinks its font to fit its square (`fitLabel`). Speech bubbles are one per character (`say`, `.bub`, `bubs`), so several conversations can show at once; a creature can talk too (`talker`).
- Fonts: Tiny5 for the board page (easy-to-read numbers), Pixelify Sans for the "Cubedom" title, a plain system font for the Compendium, Event Log and Settings pages and the description bubbles. Canvas text uses `GAME_FONT`.
- Progress saves in `localStorage` (key `cubehold-v4`, kept from the old name so saves survive).
- Game rules and data (characters, interactions, odds) stay separate from drawing code. All odds live in `ODDS`; the game and the Compendium both read them, so change odds only there.

## Files
Plain scripts, no modules, loaded in this order and sharing global variables (the order matters):
- `index.html`: page layout only. Four tabs at the top, then the Renown score (`#renown`): Board (item tray `#items` above the board, board with the weather icon `#wxIcon` in its top-right corner, character shelf `#tray`), Compendium (`#refs`), Quests (`#quests`), Event Log (`#logs`); Settings is a small pixel gear button in the top-right corner (`.tab.gear`, also a `.tab`) with How to play, Speed, Music button, Volume dial, Unlock all, Reset game. Plus `#toast` message, `#modal` purchase popup, `#away` (the time-away report) and `#help` (the How to play popup, written in index.html: board, characters, Compendium, coins and items, events and buildings, quests, weather, saving; keep it up to date when basic mechanics change). Tabs switch by their `data-t` (`#tab-board`, `#tab-ref`, `#tab-quest`, `#tab-log`, `#tab-set`).
- `style.css`: all styling.
- `data.js`: everything that is data. Characters and sprite pixels (`CH`, poses `POSE`, skin tones `SKINS`), classes and tags (`CLASS`, `EXTRA_CLASS`, `TAG_ICON`, `TAG_NAMES`), shelf (`SHELF_CHARS`, `ALL_CHARS`), items (`ITEMS`), room exits (`TR`, `EXIT`), `WEAPONS`, neighbor scenes (`PAIRS`, `ROGUE_SCENES`), `ODDS`, timers and prices (constants such as `SLEEP_TIME`, `APOTH_COST`, `INGOT_COST`), all dialogue arrays, board spaces (`START_CELLS`, `CELL_PRICE`), Compendium data (`NAMES`, `DESC`, `COMP_TABS`, `PAIR_WITH`, `EGGS`), the Monarch's colors and requests (`MPAL`, `REQ_ASK`, `REQ_YES`, `REQ_NO`), the board's weather (`BOARD_WX`, `WX_EVERY`, `WX_CHANGE_SAY`), quests (`QUESTS`, `ITEM_WORD`), helpers (`$`, `pick`, `cl`, `GAME_FONT`, `isFarm`).
- `art.js`: room walls and backgrounds (`WALL`, `bg`; textures, light and doors: `ROOM_STYLE`, `DOOR_STYLE`, `backDoor`, `ROOM_EXTRA`, `paintRoom`; each room is painted once into `ROOMC` and reused by `box`) and every drawing function: sprites (`spr`, `sid`, walking `stepLegs`, blinking `blinkMood`), arm poses per activity (`poseOf`), activity overlays (`drawAct`), weapon swings (`pracAnim`, `weaponOf`), exits (`drawFx`), room details (`drawRoomLife`), item icons (`drawItem`), creatures (`drawMob`, bats, bees, deer, birds, the Druid's bear), effects (rain, glitter, ritual darkness, sparks...), box borders (`box`, `boxFrame`), locked spaces (`drawLocked`), shop coin (`drawShopCoin`).
- `audio.js` (loaded last): music only, made with Web Audio (no sound files). Layered chiptune: one shared tempo and chord loop (`BPM`, `CHORDS`), and every room on the board adds its own part (`LAYERS`: [play, stereo position]; Knight drums, Rogue hi-hats, Fruit Merchant bass, Necromancer drone, Priest chords, Wizard arpeggio, Apothecary flute, Alchemist blips, Druid harp, Blacksmith anvil, Monarch fanfare, Traveling Merchant accordion, Farmer whistle, Well one soft low drip every two bars, Tavern jig, Bard lute plucks, Library a soft low hum, Goblin sneaky low plucks, Dragon a deep slow snore; plus a dragon battle theme), each in its own pitch range and rhythm, evened out in loudness by `MIX` (measured; the Knight, Wizard and Well are kept a bit softer on purpose), rising in quickly when its room arrives (`schedule`). The parts play through `roomBus`. Group events have their own themes (`THEMES`: chords, melody and parts for market, feast, wellchat, classic; levels `THEME_MIX`): at the start of a bar (`themeCheck`, reading `grp`) the room parts fade to a quarter and the theme comes in on `themeBus`, and back when it ends. Off by default; the Music button and Volume dial (Settings tab) are saved in `localStorage` 'sq-music'. Browsers only allow sound after a tap or click. It plays only while you are in the game: it pauses when the tab is hidden, the window loses focus or the page is put away (`musicPresence`, `AC.suspend`) and resumes on return. No sound effects.
- `game.js`: rules and everything that happens: decisions (`decide`, `startAct`, `acting`), movement (`route`, `run`), neighbor scenes (`talk`), items (`useItem`, `ITEM_FX`, `ITEM_KEY`), shops, the render loop, input, the shelf (`buildShelf`), the Compendium (`buildRef`), saving/loading.

## Board, boxes and saving
- Board: 5 columns x 4 rows, 96px cells. Neighbors are the 4 edge-sharing cells (no diagonals).
- Borders: each box draws a thin 2px frame (`box`); `boxFrame` adds 2px only on sides with no box next to it, so every border is 4px.
- Locked spaces: only the middle 3x3 (rows 1-3, columns 2-4) is open at the start (`START_CELLS`). Locked spaces are dark with a padlock and price; tap one to buy it (asks first): 10 coins, each next one 5 more (`CELL_PRICE`, `CELL_STEP`, `cellPrice`, `buyCell`). Nothing can be put on a locked space. Saved in `S.cells`, `S.bought`. Old saves keep spaces that already had boxes open for free.
- Shelf (under the board), heading "X/Y unlocked": unlocked characters first, in alphabetical order by name, then the locked ones (blank boxes with a cryptic clue and no name, `SHELF_CLUE`, `.it.locked`). Unlocked ones always show, dimmed while unavailable (on the board, or the Traveling Merchant on the road; `ui`). Drag a box onto the board (or tap it to use the first free space), onto another box to swap. Dragging a box back onto the shelf costs 10 coins (`REMOVE_COST`, `sendToShelf`, asks first); a Farmer can never go on the shelf. Placing costs coins for the Apothecary (20) and for every Monarch after the first of the game (150, `MONARCH_COST`, counted in `S.monarchs`); both ask first.
- Moving a box sends its character home. Removing a box makes the character vanish. Visitors of a moved/removed room go home, and anyone with an exit open in it too (`clearRooms`).
- Death: the box is removed and goes back to the shelf. Exceptions: the Necromancer destroyed by an artifact (removed from the shelf), the Alchemist who drinks the elixir (locked again), the Druid (buried in place, see Druid), and the Monarch (lies in state for the grand funeral first, see Gatherings). A box back on the shelf starts fresh (e.g. may ask the Monarch again).
- Settings (gear, top right): How to play (`#help`, closes with Close, a tap outside or Escape), Game speed 1x / 2x (`SPEED`, `#speedBtn`; at 2x `frame` runs `step` twice per frame and the game clock `T` adds up from `dt`, so everything goes twice as fast; music keeps its tempo; kept in `localStorage` 'sq-speed', not in the save), Music on/off and Volume, Unlock all, Reset game.
- Discovery glow: while a box is dragged (from the board or the shelf, not items), every other box on the board whose Compendium tab still has undiscovered entries gets a faint, pulsing blue glow (`hasLeft`, `drawLeftGlow`). Secrets, Super Secrets (`EGGS`) and group events (`grp:`) don't count, and it says nothing about where to put anything.
- Unlock all (Settings tab, for testing; asks first): every character, every board space and every Compendium entry, secrets included, plus 9999 coins (`UNLOCK_COINS`, not counted as spent); Renown becomes 0 for good in that game (`S.renownOff`). Their discovery rewards are not paid (`S.rewarded`, `S.bigRewarded`, `S.tabDone` are filled in).
- Reset game (Settings tab): tap once to arm, again within 4 s. Wipes the save: default board (Knight + Wizard), 0 coins, nothing unlocked, Compendium cleared.
- Event Log tab: the last 20 events, newest first, with the time (`LOG`, `LOG_MAX`, `logEv(title, detail, kind)`, `buildLog`; not saved). Logged: named neighbor scenes and visits (`logScene` in `visit` and `playScene`; the same scene twice within 4 s is logged once), uncommon and rarer idle activities (`startAct`), group events, the Druid's casts and weather changes, deaths (`kill`; a toast right after replaces the plain "has died" line) and every toast message. When adding a new kind of event, give it a `NAMES` / `TITLES` entry and it shows up by itself.
- Saved per box: row, col, weapon, form, color (outfit / gender variant), backwards speech, skin tone, Rogue's Mage tag, buried Druid, reinforced (ingot), Paladin, green mage armor, the Druid's animal, Archdruid, the Monarch's generous / greedy; and at index [15] an object of newer things by name (`EXTRA_KEYS`, `extras`): royal colors `pal`, request made `asked`, `grudge`, "Sir" `sir`, the Monarch's gifts (`helper`, `staff`, `barrel`, `sacks`, `pine`, `minions`), the Traveling Merchant's time left `travelT`. Also saved: unlocks `S.un`, `coins`, coins spent `S.spent`, items `S.inv`, Compendium `S.seen`, rewards paid `S.rewarded`, bought spaces, revealed secrets `S.revealed`, the golden spaces `S.goldCells` (an old single `goldCell` is converted), characters ever unlocked `S.ever`, Compendium tabs completed `S.tabDone`, item rewards paid `S.bigRewarded`, Monarchs placed `S.monarchs`, Traveling Merchant on the road `S.travelRoam`, quest counters `S.qs` and quests paid `S.qDone`, the board's weather `wx` (kind and time).
- Not saved: monkey, bear and beast-man forms, the Rogue's disguise and tiny size, sickness, the Necromancer's skeleton follower from the betrayal, anyone away (crusade, date, dungeon, adventure, time off), golden apples, the Alchemist's luck, the Druid's Overgrowth, Farmers, the grand funeral (a Monarch saved while lying in state is back on the shelf).

## How characters decide
- Each idle character rolls about every 5-10 seconds (`decide`): 50% an idle activity, 20% a visit, 30% wander in the room (`DECIDE`). A visit is just hanging out 20% of the time (`HANGOUT`); otherwise one scene is rolled from that visit's list (`visitRoll`, `visitList`, `playScene`).
- **Rarity tiers** (data.js, `RARITY`; never shown to the player): every list of possible events has uncommon 15%, rare 5% and legendary 0.75% entries with fixed chances; the common entries share whatever is left equally (`listChances`, `rollList`). Keep the non-common entries of one list under about 50%. The same tiers are used for outcome chances inside scenes (deaths, special results: `ODDS.slip`, `horde`, `boomDeath`, ... set from `RARITY`). Plain splits are left as they are (date success, blood orange 30%, crusade reward 70/30, dungeon loot, looks like outfits and King/Queen).
- **Idle lists** (`IDLES` per character, `IDLE_ANY` for everyone): `[key, tier, condition]`; an entry with a condition (`idleOk`) only joins while it holds (`idleList`, `startAct`, `doIdle`). **Visit lists**: the arrangement's scene from `PAIRS`, or several (`VISIT_EXPAND`), plus any-side scenes (`VISIT_ANY`; `fallback` = only when the pair has no common scene) and the visitor's group scenes (`VISIT_GROUP`: great prayer, four Mages, adventure). The Druid's casts use `WEATHER_TIERS`, the board's weather `BOARD_WX`.
- Modifiers: the Alchemist's luck makes rare and legendary visit scenes 30% more likely; the board's weather (see Weather): Sunny +10 points of visits, Rainy +15 points of idle, Fae Wind the rarest tier x4.
- Visit chance changes: Knight or Wizard in Old Friends 45%; Knight with a Priest above x1.6 (Zeal); a Mage next to the Alchemist x1.2.
- The Druid never visits: his visit roll casts Overgrowth or, rarely, changes the weather instead (see Druid), except once to make his request when the Monarch is his neighbor. Others can still visit him.
- A greedy Monarch never visits. The Traveling Merchant never visits and nobody visits him (`nbrs` leaves him out).
- A visit to the Monarch by someone with a request they haven't made yet (`reqOf`, `u.asked`) is always that request.
- Which neighbor: random among free ones (`nbrs`, `freeU`), except a Fighter next to the Alchemist picks Mages 50% more often (haste potions, `pickW`).
- Some scenes always have the same visitor (noted below). The per-scene percentages written in the sections below are older notes on the arrangement; the tiers in `IDLES` / `VISIT_EXPAND` / `VISIT_ANY` / `VISIT_GROUP` are what counts (the Compendium shows the resulting %).
- Scenes play at `SCENE_PACE` (0.65) so they last a little longer. Asleep, away, sick (for visits), Death Knights, temporary forms and the buried Druid don't roll normally.

  - **Rainy** U: idle +15 points, taken from visits (`WX_RAIN_IDLE`: 65 / 5 / 30). Soft falling rain over the whole board (`drawBoardWx`).
  - **Fae Wind** L: the rarest tier in every idle and visit list is 4 times as likely (`WX_FAE`, `faeMult`, used by `idleMult` and `visitRoll`), taken from the common entries (`listChances` scales the fixed chances down if they would pass 100%). Pink wind streaks and sparkles drift over the board.
- The icon in the top-right corner of the board (`#wxIcon`, `showWx`, pixel art `WX_ICON` / `drawWxIcon` in art.js): a sun, a sun behind a cloud, a rain cloud, pink wind. Tap it for a toast with what the weather does.

## Quests (tab `#tab-quest`, `#quests`)
- Story quests (`QUESTS` in data.js: `{id, name, text, stat or tab, goal, reward, show}`), at the top of the Quests tab: shown only once `show()` holds, with a "New quest" pop-up the first time (`S.qShown`, saved); paid once (`S.qDone`), even during the grand funeral.
  - **An Old Friend:** every entry on the Wizard's Compendium page in the whole game, secrets and entries with characters not unlocked yet included (`tab:'wizard'`, `questProg` counts all of the tab's pairs, idles and items). Shown once every one of those entries can show (`wizardAllShown`: every partner unlocked). Reward: the Bard is unlocked (`reward.unlock`).
  - **The Rumors are True:** the Fruit Merchant tells the Knight about goblins 5 times (`goblinRumors`, counted in the `rumors` scene when it is the goblin version). Shown once the Fruit Merchant is unlocked. Reward: the Goblin is unlocked.
- Daily quests (`DAILY_QUESTS`, `DAILY_COUNT` 3): picked once a real-world (local) day at random among the ones whose `avail()` holds for what you have unlocked (`dailyRefresh`, `S.daily` {date, ids, qs, done}, saved; a toast when a new day's set arrives); their counters start over each day. Prosperity (3 feasts, 50 coins; 3 characters unlocked), Feast Fit for a King (a feast with the Monarch, 1 artifact; Monarch unlocked), Cost of Discovery (the Wizard dies 5 times, 5 scrolls), Big Spender (spend 50 coins buying from characters: their shops, `spend(n, true)`, +1 renown), Blink and You'll Miss It (a rare or legendary event, 5% or less: idle and visit rolls and the Druid's casts, 15 coins), They Will Be Missed (a character dies, 5 coins), Lore Gatherer (10 new discoveries; reward: reveal an undiscovered Compendium interaction, `revealScene`; only with 10+ left), Market Day (a market day, 30 coins; 4 Merchant-tagged characters unlocked).
- `questStat(stat, n)` counts toward both (`S.qs` for good, `S.daily.qs` for today). Rewards (`payQuest`): `coins`, items, `unlock` (a character), `renown` (`S.renownBonus`), `reveal`. `checkQuests` also runs from `checkDiscoveries`. To add a story quest: an entry in `QUESTS` with a `stat` or a `tab`, and `show()`; a daily one: an entry in `DAILY_QUESTS` with `avail()`.

## Renown and time away
- **Renown** (`#renown`, next to the Event Log tab; tap it for what it is): the kingdom's score, to compare runs or with friends (`renownOf`): 1 per Compendium discovery, 10 per character unlocked for the first time (`RENOWN_CHAR`, from `S.ever`, structures not counted), plus quest rewards (`S.renownBonus`, saved). Using Unlock all sets it to 0 for good in that game (`S.renownOff`, saved; until Reset). It pops when it goes up (`showRenown`, from `markSeen`, `buildShelf`, `payQuest`).
- **Time away** (`awayReport`, the `#away` popup "While you were away"): the save keeps when you were last here (`lastSeen`, saved every 30 s of play `autoSave`, and when the page is put away); on load, or when the tab comes back after being hidden (`visibilitychange`), 5 minutes or more away (`AWAY_MIN`) gets a report. Only the last 8 hours count (`AWAY_MAX`). Coins are halved (`AWAY_COIN`) and added straight to your purse, so nothing unlocks: the Bard's passers-by coins (tags x 5-minute stretches); the Goblin's stash also grows (his). The weather is rolled once per 10 minutes. No scenes or events play. Each hour away has a 2% chance (`AWAY_REVEAL`) to reveal an undiscovered interaction. Plus flavor lines about up to 4 characters on the board (`AWAY_LINES`, "about {n} times"), or `AWAY_IDLE` if nobody is there; it also goes in the Event Log. Clock tricks: the save keeps the latest time it has seen (`maxSeen`); with the clock moved back there is no report, a report needs 5 minutes of real play since the last one (`S.playT` real seconds played, `S.awayAt`, `AWAY_PLAY_MIN`), and daily quests only change on a LATER day (`dayOf`, `S.daily.day`).

## Items, coins and shops
- Items are a counted inventory (`S.inv`): spell scroll, potion, artifact, ingot. Drag one onto a room; it works only if the owner is home and not busy. If nothing happens it isn't used up (grey puff). An effect returning `'keep'` happens but gives the item back.
- **Spell scroll:** Wizard fireball (destroys a neighboring room and everyone in it); Knight golden glow 30 s; Priest banishes a ghost; Necromancer raises a skeleton next door; Fruit Merchant becomes a monkey 2 min; Apothecary brews it into a potion; Alchemist tears it up; Rogue gains the Mage tag; Druid: he reads it to the sky and the board's weather changes to another one, picked at random (`druidWx`); Blacksmith: the spell goes wrong and he dances uncontrollably for 15 s; Goblin: he can't read it and tosses it onto his junk pile (`gscroll`, act `gtoss`); buried Druid: revived.
- **Potion:** Wizard teleports to someone for a scene; Knight flexes; Priest angel wings 30 s; Necromancer smashes it; Fruit Merchant speaks backwards (toggles); Apothecary buys it back (+10); Alchemist: luck potion (60 s, his and his neighbors' rarest chances +30%, their squares glitter); Rogue: invisible prank (`rogueSpook`); Druid saves it for a rainy day (used up); Blacksmith hands it back; Goblin: he sniffs it, looks confused and pours it out (`gpotion`, act `gpour`); anyone asleep wakes up.
- **Artifact:** Priest next to the Necromancer destroys him (secret). Alchemist: 80% philosopher's stone (one more space turns golden for good, they add up; coins earned on a golden space are doubled, `S.goldCells`, `inGold`; with every space golden: +50 coins instead), 20% elixir of life (he retires, secret). Druid: becomes the Archdruid.
- **Ingot:** on anyone without the Fighter tag: reinforced, Fighter tag for good (`reinforce`). Unlike scrolls and potions it works even while the character is busy or out of their room (not while away). The Monarch: nothing (kept). The Druid refuses it and hands it back (`dingot`). The Traveling Merchant buys it (+30, no tag).
- **Traveling Merchant:** buys a spell scroll or potion for 15 coins and an ingot for 30 (`tSell`, `TRAVEL_BUY`).
- **Shops:** a small gold coin in the bottom-right corner of a shop room (`drawShopCoin`, `onShopCoin`). Apothecary: potion, 30 coins (with the Alchemist next to her, 20% you get two, secret; with the Druid next to her, 5 coins less, secret, `DRUID_DISCOUNT`). Wizard (while a Merchant and another Mage are next to him): scroll, 50 coins (30 for the black Wizard). Blacksmith: ingot, 100 coins. Traveling Merchant: artifact, 300 coins (`buyArtifact`). No shopping during the grand funeral. Every purchase asks first (`ask`).
- **Coins:** no passive income. Coins come from the Wizard's advertising, scenes and idles (sales, customers, tithe, starfruit, durian, blood orange, crusade, dungeon, adventures, farms, lead into gold) and Compendium rewards (every 5 discoveries pay 10). Compendium item rewards (`checkDiscoveries`): a character's tab fully discovered, secrets included, +1 artifact (once per tab); every 50 discoveries (`BIG_EVERY`) one random item: spell scroll 45%, potion 45%, ingot 10% (`ODDS.bigReward`). They pay even during the grand funeral and are paid on load if already earned. Spending goes through `spend()` (counted in `S.spent`).
- **Where items come from:** scrolls from crafting, joint making, the Wizard's desk, the dungeon, adventures; potions from the Apothecary, the Wizard brewing, joint making, a scroll on the Apothecary, the dungeon; artifacts from the crusade, the dungeon, adventures, the royal patron, the Rogue's conjuring, the Traveling Merchant's shop; ingots from the Blacksmith's shop and his mold pouring.

## Transitions between rooms
- Left/right: the Wizard uses portals; everyone else walks through the side door (it swings out into the next room). Rooms without side doors (`noSideDoor`: farms, forest, the Traveling Merchant's road, the Well, the Rogue's graveyard) are crossed by walking over the edge.
- Up/down use each ROOM's exit (`TR`, `exitsOf`): back-wall door (Knight, Priest, Necromancer, Fruit Merchant, Blacksmith); a fancy one (Monarch, `royaldoor`, which also gives fancy side doors to and from the throne room); the same door on the left (Apothecary, Alchemist); a sliding bookshelf (Wizard); rope and trapdoor (Rogue); fade (Farmer, the Rogue's graveyard); shadow between trees (Druid). Leave by your room's exit, arrive by the other room's.
- Not neighbors (potion teleport): a pair of portals.

## Compendium tab
- Tabs are in alphabetical order. One tab per character ever unlocked (`COMP_TABS`, `compUnl`; it stays even if the character is locked again, e.g. the retired Alchemist, `S.ever`), with found / total (`tabKeys`). A neighbor scene only shows once both characters are unlocked (`PAIR_WITH`; 'anyone' and `tag:...` count as unlocked).
- Under the tabs: the "Discovered" line and the **Decisions** line (no Tags line).
- Groups: Passive abilities (at the top; `PASSIVES` in data.js, e.g. the Goblin's stash, the Bard's Resonance), With neighbors (one sub-section per neighbor, alphabetical: "with the Knight", "with a Mage", "with anyone"), Idle activities, Items and shops, Secrets (at the bottom; "Not found yet" until one is found or revealed).
- A tab's top lines: "Discovered X of Y" (Y = everything in the game, `ALL_KEYS`), then **Decisions.** (`decideText`, `DECIDE_NOTE` exceptions).
- Tile pictures show the tab's own character where possible: a scene "with a Mage" (Fighter, Merchant, Monstrous) normally drawn with a stand-in (`TAG_STANDIN`: Wizard, Knight, Fruit Merchant, Goblin; the mad Alchemist only appears in his own secrets) shows the tab's character instead in another tagged character's tab (`tileArt`, which sets `SWAP` for `spr` and `box` while the tile is drawn).
- Every description (clue or found) starts with the entry's title in bold and a period (`titleOf`: `TITLES` in data.js, short Title Case names, else `NAMES`; no period is added after "?" or "!"; `showTip`).
- Tile chances come from the rarity lists (`pctOf`: `idlePct`, `visitPct`, weather): the % when that kind of action happens, "of his idle activities" or "of their visits" (hangouts included). An idle's common share counts the character's whole list. Percents are rounded DOWN (`fmtPct`) so one list never adds up past 100%. Request tiles show "80% / 10%" (granted by a generous / greedy Monarch).
- A discovered (or revealed) tile's description (`infoText`): "Visit (64% chance): Priest left of the Knight. <story> <outcome note>" (also Idle, Weather, Item; `whereText` from `PAIRS`, `IDLE_COND`, `NOTE`). The story (`flavorOf`: `DESC` without its rules, or `FLAVOR`) is the same as in the clue. Other tiles (shops, special secrets, passives) show their `DESC`.
- The clue of an undiscovered tile (`hintOf`) = the story plus a playful unlock hint (`unlockHint`: hand-written `HINTS`, else made from the rules with compass words: west = left, east = right, north = above, south = below; "A rare sight." / "Once in a blue moon." for rare chances).
- Undiscovered tiles are a blank square with a "?" (`tile unknown`); the sub-heading counts (e.g. 1 / 7) still show how many there are with each character or tag. Hovering one shows a hint (`hintOf`): its description without the leading sentences about placement, items or chances (`HINT_CUT`, `HINT_HEAD`), with "30% more" turned into "more" and any other sentence with a chance dropped. Once discovered or revealed, the tile shows its image, chance and full description.
- Tiles show the chance top right (from `ODDS`), icons bottom left for what a scene gives (`GAINS`), a gold border once it has happened (`markSeen`, `S.seen`); found secrets get a purple dashed outline. Hover or tap a tile for its `DESC` description (`showTip`), written with a little humor.

## Drawing and animation conventions
- Pixel art: characters are designed on a 16x22 grid from rectangles (`CH`, `POSE`, plus hand-placed details `SPRITE_DETAIL`, matched by the start of the sprite name, drawn over the body and under hands in front, moving with the legs) and drawn chunky (`drawSprite`, cached by `sprite`): a dark outline one grid pixel thick (`outline`) and blocky shading with light from the top-left and a gentle falloff toward the feet (`shadeSprite`) and the face (`drawFace`: simple pixel eyes and mouth per mood, drawn after the shading so they stay crisp) on the 16x22 grid, then doubled to 32x44 with square pixels (no smoothing). Skin tones and outfit variants are copies of the 16x22 design, so they keep working. Fantasy medieval theme. Keep the top-left of a room (about y < 24) clear for the name label.
- Arms come from `POSE` (none, hold, noR, fwd, up, wave, both, pray, flex, flex2); `poseOf` picks one per activity; short gestures use `gest`. Kneeling uses `pray`.
- Walking: legs step apart in two frames (`stepLegs`, `stepOf`). Moods: ok, happy, mad (real anger and monsters only), hurt, shock (surprise; never red eyes for surprise), sleep, roll (rolling the eyes). Characters blink (`blinkMood`).
- Outdoor rooms (farm, the Druid's forest by row, the Traveling Merchant's road; `OUTDOOR`, `outBack` behind their bg rects: sky gradient, clouds, hills, mountains, far trees, sun shafts; `outFront` in front: grass tufts, bark, ferns, glowing specks, light). The farm has a red barn and hay; the road a covered wagon, mule, crate and barrel (no stand).
- Room look (`paintRoom`, painted once per room and weapon / row / colors, cached in `ROOMC`): wall fill and texture (`ROOM_STYLE` wall: stone, block, brick, plank, plaster), floor texture (flag, plank, dirt), the room's bg rects, extra decor (`ROOM_EXTRA`: the Knight's banner, torch and rug, the Wizard's star chart and rug, the Priest's arch, light beams, pillar and carpet, the Necromancer's cobweb, chain and rune circle, the Fruit Merchant's sign, onions and mat), then soft light (`roomLight`). Outdoor rooms (forest, road, farm) have no style. Change a room's look in these, and the cache picks it up on reload.
- Doors: each room has its own door look (`DOOR_STYLE`: wood, seams, straps, rivets, knob, frame, arch, a decoration such as the Priest's cross, the Necromancer's skull, the Apothecary's wreath, the Alchemist's porthole). The back door rects come from `backDoor(id, left)`; opening doors (`drawFx`) use the style of `f.room` (an arched door, `arch`, swings with its arched top and leaves an arched opening) (a side door looks like the room you leave; to or from the throne room it is always royal).
- Rooms have small moving details (`drawRoomLife`): the Knight's torch, the Wizard's candles, candles, a cloud, book sparkles, the Alchemist's flask, the forge fire, falling leaves (glowing spores in the mushroom forest), the jester juggling.
- Visitors stand at least 30px beside their host (`standBy`). Facing only flips when the other is clearly to one side. Weapons are drawn only while used, clipped to the room.
- Extra people in a scene live in `u.crowd`, a single helper in `u.npc`, creatures in `u.mobs`, a follower in `u.pet`.

## Editing the Compendium text
- `tools/compendium-export.html` makes a text file of every Compendium entry tab by tab (it is not kept in the project; make it again when needed): `[key]`, Name (`NAMES`), Story (`flavorOf`: `FLAVOR`, else `DESC` without its rules), Hint (`HINTS`, or "(auto)" from `unlockHint`), Note (`NOTE`), and the full text once found (reference only), plus the shelf clues (`SHELF_CLUE`).
- To make it again: run `tools/compendium-export.html` in headless Edge (`msedge --headless=new --allow-file-access-from-files --dump-dom file:///.../tools/compendium-export.html`), take the text of `<pre id="out">` and unescape `&lt; &gt; &quot; &#39; &amp;`.
- When edits come back: a changed Story becomes a `FLAVOR` entry, a changed Hint a `HINTS` entry, Name a `NAMES` entry, Note a `NOTE` entry (all in data.js).
